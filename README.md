# BenefitBeyond™
**More than SSDI. More possibilities.**

A vibrant, mobile-first resource explorer for disability-related benefits, money-saving programs and everyday budget tips.

## What's included
- Searchable national and state resources with eligibility notes and official provider links
- A responsive colorful design, designed for visitors with large readable controls
- 20 original, economical recipes and a browser-local grocery list
- Favorites saved locally on the visitor's device
- Weekly savings calculator
- Advertise With Us pricing

## Important limitations
The current GitHub build includes 22 starter resource listings, not the entire previously researched 87-item local catalog. The earlier downloadable project is a separate local artifact and has not been completely migrated into this repository yet.
- Benefit and discount requirements change. SSDI alone does not qualify a visitor for every program. Visitors must confirm requirements with official providers.
- This is an independent informational website, not an SSA or government service.
- The advertisers' pricing page is informational. **No live payments, order system or advertiser account backend is connected.**
- The page is static: no automatic benefit updates, real user accounts or visitor tracking.
- Browser favorites and grocery lists stay on the visitor's device.
- No claims of approved offers, guaranteed eligibility or verified advertisers.

## Run
Open index.html in any modern browser or connect this repository to a static hosting service such as Vercel.
